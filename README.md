# Multimodal Generative Sequential Recommendation with Adaptive Contrastive Learning

Chang Sun, Long Chen, Mengyao Jiang, Bin Wu.

## Environment Requirement 

The code has been tested running under Python 3.12.4. The required packages are as follows:

- torch == 2.7.1
- numpy == 1.26.4
- scipy == 1.10.1
- pandas == 2.3.1

## Dataset

We use four publicly available datasets: Amazon, Yelp, MicroLens, and Movielens.
